HD video backgrounds, in sync

Want Clone Hero music videos without hunting for them? Select songs and press Run. The app finds the official music video, downloads it, and lines it up with the chart by matching the video's soundtrack against the chart audio. Only 640p or better is accepted, so no blurry uploads and no album-art slideshows. Step by step: how to add music videos to Clone Hero, and which video formats Clone Hero uses on each system.

Clone Hero lyrics, sing along

Charts that have a vocals part already show lyrics. For the rest, time-synced lyrics from LRCLIB are written into the chart and aligned to its own audio, so Clone Hero shows them in game.

Prefer to leave charts untouched? Switch lyrics off in one setting. Every change is backed up first and Undo restores the originals. See how to add lyrics to Clone Hero songs.

Install

Everything is bundled, ffmpeg and yt-dlp included.

  1. Open the .dmg and drag Clone Hero Companion to Applications.
  2. The app is ad-hoc signed, not notarized. On first launch, right-click it and choose Open, then Open again.
  3. If macOS asks about protected folders, grant Full Disk Access (Game & folders, then Grant Full Disk Access).
  1. Run the .msi installer, then open Clone Hero Companion from the Start menu.
  2. This release is unsigned; Windows may show an unknown-publisher warning. If folder writes are blocked, allow the installed app through Controlled folder access.
  3. The window uses Microsoft Edge WebView2, which ships with Windows 10 and 11.
  1. Extract the archive: tar xzf CloneHeroCompanion-linux-x64.tar.gz
  2. Make it executable and run it: chmod +x CloneHeroCompanion && ./CloneHeroCompanion
  3. It opens in Chrome, Chromium or Edge app mode if installed, otherwise in your browser.

Then in Clone Hero, turn on Settings, Custom Content, Song Videos.

Frequently asked questions

Is Clone Hero Companion free?

Yes. It is free and open source under the GPL-3.0 licence, with no ads and no paid tier. You can read the code and download every release on GitHub.

Does it work with Clone Hero on Mac, Windows and Linux?

Yes. There are builds for macOS 11 or newer (one universal build for Apple Silicon and Intel), Windows 10 and 11, and Linux x64. On Linux, videos are saved as VP8 .webm, the format Clone Hero plays there.

How do I add music videos to Clone Hero?

Install the app, point it at your Clone Hero songs folder, select songs in the library and press Run. It finds a video for each song, downloads it and syncs it to the chart. Then turn on Settings, Custom Content, Song Videos in Clone Hero and the video plays as the background of the chart.

Where do the videos come from?

Videos come from YouTube. Only HD results of 640p or better are accepted, so low-quality uploads and album-art slideshows are skipped. The soundtrack of the video is matched against the chart audio to line the two up, and you can nudge the timing by hand in the sync editor.

Does it modify my charts?

Only when it has to, and never without a backup. Adding a video places a video file next to the chart. Lyrics are written into the chart only for songs that have none, and you can switch that off in one setting. Every change is backed up first, and Undo restores the originals. Both folder charts and .sng files are supported.

Do I need an account?

No. Everything works signed out and offline. An account is optional and only adds syncing of your favourites and play stats between computers. You can sign in with Google or a six-digit code sent to your email.

Is it affiliated with Clone Hero?

No. Clone Hero Companion is an independent community project. It is not affiliated with, endorsed by or sponsored by Clone Hero or its developers.

How do I install it on macOS?

Open the .dmg and drag the app to Applications. The app is ad-hoc signed but not notarized, so on first launch right-click it, choose Open, and click Open again. If macOS asks about protected folders, grant Full Disk Access.
